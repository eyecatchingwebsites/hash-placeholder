Windows Defender stopped mining

Mining software often gets flagged because it uses your graphics card the way some malware does. Defender's AI guesses; it doesn't know. Hashcoin isn't code-signed, so Windows has less to go on.

The installer's SHA-256 is published on the website, and the code is public on GitHub. Miner files only run if they match their published SHA-256. Hashcoin never changes your security settings.

Allowing it is your choice. To allow it:

  1. Open Windows Security.
  2. Go to Virus & threat protection → Protection history.
  3. Select the Hashcoin item, then Actions → Allow on device. If there are two (the app and the miner), allow both.
  4. Reopen Hashcoin.
