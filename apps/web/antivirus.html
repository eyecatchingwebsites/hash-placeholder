Antivirus and Windows warnings

Windows or your antivirus may warn you about the Hashcoin app. Here's why, how to check it's ours, and how to allow it if you choose to.

Why it happens Check it's ours "Windows protected your PC" Allow Hashcoin

Why it happens

Mining uses your graphics card the way some malware does, so many antivirus products flag every crypto miner, legitimate ones included. Their AI makes a guess; it doesn't know.

The Hashcoin app isn't code-signed yet, so Windows has less to go on and may warn you the first time you run it.

We never ask you to turn off your antivirus, and the app never changes its settings. Allowing Hashcoin is your choice.

Check it's ours

  • Download it only from this site. Not from links in DMs, ads or other sites.
  • Compare the checksum. Each installer's SHA-256 is listed next to the download. To see yours, open PowerShell and run Get-FileHash followed by the installer's path. The two must match exactly.
  • Read the code. The app is open source on GitHub.
  • Miners are checked too. The app only runs a miner file whose SHA-256 matches the list our server signs.

If Windows says "Windows protected your PC"

This is SmartScreen. It shows for new apps that aren't code-signed or widely downloaded yet.

  1. Click More info.
  2. Check the app name is Hashcoin Miner and that you downloaded it from this site.
  3. Click Run anyway.

Allow Hashcoin in your antivirus

If your antivirus stopped mining, find Hashcoin in its quarantine or history, restore it and allow it. There may be two items, the app and the miner; allow both. Menu names change between versions, so if a step doesn't match, look for Quarantine, History or Exceptions.

Microsoft Defender (Windows Security)
  1. Open Windows Security → Virus & threat protection → Protection history.
  2. Select the Hashcoin item → Actions → Allow on device. If there are two items, allow both.
  3. Reopen Hashcoin.
Norton 360
  1. Open Norton → Security → History → show Quarantine.
  2. Select the item → Options → Restore & exclude this file.
  3. Reopen Hashcoin.
McAfee
  1. Open McAfee → My Protection → Quarantined items, select the item → Restore.
  2. Then My Protection → Real-Time Scanning → Excluded files → Add file.
  3. Reopen Hashcoin.
Avast and AVG
  1. Open the menu (☰) → Quarantine → the … next to the item.
  2. Choose Restore and add exception.
  3. Reopen Hashcoin.
Bitdefender
  1. Open Protection → Antivirus → Settings → Manage quarantine, select the item → Restore.
  2. Then Antivirus → Settings → Manage exceptions → Add an exception.
  3. Reopen Hashcoin.
Kaspersky
  1. Open Security (or More tools) → Quarantine, select the item → Restore.
  2. Then Settings → Security settings → Exclusions and actions on object detection → Manage exclusions → Add.
  3. Reopen Hashcoin.
ESET
  1. Open Tools → Quarantine.
  2. Right-click the item → Restore and exclude from scanning.
  3. Reopen Hashcoin.
Malwarebytes
  1. Open Detection History → Quarantine, select the item → Restore.
  2. Then Detection History → Allow list → Add → Allow a file or folder.
  3. Reopen Hashcoin.

If your antivirus asks for folders instead of files, they are %LOCALAPPDATA%\Hashcoin Miner (the app) and %LOCALAPPDATA%\com.hashcoin.miner\miners (the miners).
