# Hashcoin logo

Option C (italic hash), coin color **#EBB447**, hash **#FFFFFF**. Chosen October 3, 2026.

| File | Use |
|---|---|
| `hashcoin-mark.svg` | Master logo (vector). Use everywhere possible |
| `hashcoin-{16..1024}.png` | Token icon (512 for launchpads, DEX listings, wallets), X avatar (512/1024) |
| `favicon.ico` | Website favicon (16/32/48/64) |
| `hashcoin-mark-dark-hash.svg`, `hashcoin-dark-hash-512.png` | Alternate with a dark hash (#15110D). Higher contrast on the gold, better if the icon looks soft at tiny sizes |
| `hashcoin-hash-gold.svg` | The hash alone in gold, for watermarks and 3D/emboss work |
| `hashcoin-lockup-light.svg/.png` | Logo + "Hashcoin" wordmark on light backgrounds |
| `hashcoin-lockup-dark.svg/.png` | Same, white wordmark, for dark backgrounds |

Wordmark font: Manrope ExtraBold (free, Google Fonts). The SVG lockups reference the font by name. For print or exact sizing, convert the text to outlines in a vector editor, or use the PNGs.

Note: white on #EBB447 has a contrast ratio of about 1.9:1, so the hash is softer at 16 px than a darker gold would be. That's fine for a logo. If the favicon looks faint, switch to the dark-hash version for the tiny sizes.
